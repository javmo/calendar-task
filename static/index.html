🔧 Configuración Inicial

Para usar la app necesitás configurar Firebase Authentication.

Paso 1: Crear proyecto Firebase

Andá a Firebase Console → "Agregar proyecto" → Ponele un nombre (ej: "calendario-tareas")

Paso 2: Activar Google Sign-In

En tu proyecto → Authentication → Sign-in method → Habilitar Google

Paso 3: Obtener config web

Project Settings → General → "Your apps" → Web () → Registrar app → Copiar el objeto firebaseConfig

Paso 4: Pegar config en la app

Abrí static/index.html y reemplazá los valores YOUR_... en FIREBASE_CONFIG (línea ~4 del script)

Paso 5: Service Account (backend)

Project Settings → Service accounts → "Generate new private key" → Guardalo como firebase-sa.json en la raíz del proyecto

⚠️ Después de configurar, recargá la página. Si estás en modo desarrollo sin Firebase, la app funciona igual con auth deshabilitada.
